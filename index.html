GROWZY API Control Hub

Welcome to the interactive presentation suite. This dashboard allows you to present the entire API capabilities of the GROWZY project in real-time to your instructor. You can edit parameters, send live requests, and inspect responses directly from your local XAMPP server.

⚡ Live Testing Playground

Interact directly with the local PHP routes. You don't need Postman; everything can be executed right here inside the dashboard.

🔑 Intelligent Auth Sync

Logging in will automatically capture the returned JWT access token, store it, and attach it to requests that require authentication.

🔧 All Modules Supported

Fully supports testing the Authentication flow, User Profiles, Feedback systems, Business Ideas, and Requests.

🎨 Clean presentation interface

Designed with visual excellence in mind. Ideal for projection screens and classroom presentations.
